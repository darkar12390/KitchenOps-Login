# KitchenOps mobile login

Prototype built with React Native, Expo, TypeScript, and Expo Router.

## Run

```bash
cd ~/Documents/KitchenOps
npm start
```

Scan the QR code with Expo Go, or press `i` for the iOS simulator / `a` for Android.

## Demo access

- User: `demo`
- Password: `1234`

The prototype validates credentials locally, opens a three-step post-login welcome, and stores no data.
